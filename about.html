About the Project

Explore Delhi is a mini-project for the course Web Development (2026FSWD100). Its goal is to give tourists and students one simple, responsive website for Delhi's places, food and trip enquiry.

Objectives

  1. Show at least 12 tourist places in 4 categories.
  2. Provide a category filter using JavaScript.
  3. Provide a validated trip enquiry form.
  4. Make the website responsive for mobile and desktop.

Technologies Used

  • HTML5 (semantic tags, lists, tables, forms, media)
  • CSS3 (selectors, box model, position, Flexbox, media queries)
  • JavaScript (events, DOM manipulation, form validation)
